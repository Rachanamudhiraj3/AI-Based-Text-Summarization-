\# AI-Based Text Summarization Platform



\## Features



\- Text Summarization

\- PDF Summarization

\- Bullet Point Generation

\- Keyword Extraction

\- Drag \& Drop PDF Upload

\- Download Summary as PDF

\- Dynamic User Interface

\- Responsive Frontend Design



\## Tech Stack



\### Frontend

\- React.js

\- Axios

\- CSS



\### Backend

\- Node.js

\- Express.js

\- Multer

\- pdf-parse

\- dotenv



\### AI / NLP

\- Hugging Face Inference API

\- facebook/bart-large-cnn model



\## Installation \& Setup

\- cd AI-Based-Text-Summarization-Platform



\### Backend Setup

\-cd server

\-npm install(Install Dependencies and Required Packages)

\-create .env File(i have used huggingface API for my project)

\-node server.js

\-backend runs on "http://localhost:5000"



\### Frontend Setup

\-cd client

\-npm install (Install Dependencies and Additional Packages)

\-npm start

\-Frontend runs on "http://localhost:3000"
